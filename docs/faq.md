FAQ: this file answers questions that are usually asked.

Q: Why doesn't Emotion C have a header file format?
A: Because it wasnt implemented YET. It'll be implemented in version 2, you can check out the website: https://emotionc-lang.pages.dev for more news.

Q: Why isn't Emotion C a program language when it is one?
A: Because Emotion C is a translation layer bewteen C^_^ and C++, but it is a source-to-source compiler.

Q: Why don't you say Emotion C is a program language?
A: Same answer as Q:2.
